项目二说明文档
一、项目简介 本项目基于 RLE（行程编码）实现简单图像压缩解压，针对 PPM 格式图片。程序读取images目录下原图，提取像素进行行程编码，将编码结果保存为JSON；之后读取JSON文件解码，重建图片输出至 restored。拓展功能实现压缩率自动统计与异常捕获。
二、核心实现思路 1. 程序输入：images文件夹内后缀为 .ppm 的图像文件。程序遍历目录自动筛选图片。2.核心处理步骤 1. 读取图片：PIL 打开图片，调用 getdata获取像素序列 3. RLE 编码：扫描像素序列，连续相同像素合并为 [像素值，连续个数]，压缩结果连同宽高存入 JSON 3. 保存压缩文件：将编码后的 RLE 序列、图片宽高写入 JSON 文件，保存至 compressed 4. RLE 解码：读取 JSON，解析行程序列，还原完整像素列表；JSON 存储时 RGB 元组会转为列表，解码阶段转回 tuple，解决 PIL 报错 5. 重建图像：使用还原后的像素重建图片，进行输出和保存。6.容易出错的地方路径问题：代码路径和实际文件夹位置不一致，程序找不到图片，元组转列表：JSON 无法保存 tuple，RGB 像素存入 JSON 自动变为列表；直接传给 PIL 会抛出 color must be int or tuple，解码时必须手动转回元组旧缓存文件：compressed 内遗留上一轮旧 JSON，会持续读取旧错误数据，每次重新运行前建议清空
三、异常输入处理逻辑，代码加入异常捕获机制： 1. 损坏图片：图片文件损坏无法打开时，捕获异常，跳过当前文件继续处理其余图片，程序不会直接崩溃终止 2. 非目标格式：自动过滤非 .ppm 文件，不会尝试读取其他后缀文件 3. 文件夹缺失：使用 os.makedirs(exist_ok=True)，输出目录不存在时自动创建，避免目录不存在报错。
四、开发进度和已完成模块：1.目录遍历，自动读取原始PPM；2.RLE编码，保存为JSON3.RLE解码，重建还原图片；4.压缩率自动统计输出；5.异常捕获，跳过损坏文件。
